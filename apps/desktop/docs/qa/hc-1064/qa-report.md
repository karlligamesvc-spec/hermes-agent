## 守卫

`src/apex-avatar-identity.test.tsx`（硬规则 11）：

- 是我们自己画的：几何和颜色逐个钉住；任何状态下都没有 `img` / `image` / `use` / `foreignObject` / `href` / `src`；源码和样式表里没有资源路径、`url(`、`nous`、`hermes`。
- 只在单线产品模式出现：只有单线专用文件能 import 它；开关关和开发者模式下，侧栏和做事中的对话里都画不出它；开关开时活动行有一个，眼睛往下看。
