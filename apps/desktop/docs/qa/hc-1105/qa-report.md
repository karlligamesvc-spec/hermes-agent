# hc-1105 — 单线关或开发者模式下，自己发的消息也能选中、复制

## 范围

hc-1101(#522)只修了单线产品模式。这张票补上另外两种情况：单线开关关着，以及开发者模式(单线开着也一样，对话区走同一条路)。这次有意改了开关关时的行为，所有人都会碰到，Kael 同意开票(PD 第 1042 行 K 列)。

**做法:「点气泡进编辑」不动(上游的交互),只让字能选、能复制。**

- 气泡仍是那个按钮，单击照样打开编辑框。悬停栏、外观、DOM 都不变。
- `styles.css` 加了一条规则，只管这个按钮和它里面的字：`user-select: text`。原来全局的 `button { user-select: none }` 让它选不中。
- 拖选结束的那一下点击不进编辑。这个保护上游本来就写了(`hasTextSelection()`),只是以前字选不中，走不到。
- 右键整条「复制」:表情回应关着时(默认),右键气泡弹应用菜单，只有「复制」一项，复制整条，复制内容和单线模式一样(`copyableMessageText`)。不加时间，因为开发者模式下 APEX 回复的右键也没有时间。
- 按下气泡时，对话区会为编辑框锁住滚动(`notifyThreadEditOpen`)。现在按下可能以选字结束，所以松手时再判断一次(`holdForBubblePress`):
  - 以选区结束：不进编辑，放开锁定；
  - 只是点掉了旧选区：照样进编辑，这时补上锁定；
  - 右键不锁定。

## 为什么不加悬停「复制」

单线模式下悬停栏在气泡左边，有空间放「复制」「改一下」。开关关和开发者模式下，悬停栏在气泡**里面**的右下角，气泡只给一个图标留了 `pr-9`(「恢复」或「停止」)。再加一个「复制」，会盖住最后一行的字；要不盖住，就得给所有气泡加宽右边距，那会让每条消息的折行都变。所以这两种模式下，整条复制走右键，部分复制走拖选 + ⌘C。如果要悬停「复制」，需要另外定版式。

## 出口清单(硬规则 12)

### 模式

| 模式 | 气泡 | 本 PR |
|---|---|---|
| 单线产品模式 | 普通块(#522) | 不动。`single-thread-chat.css` 一字未改，单线的测试照旧全过 |
| 单线关 · 产品模式 | 点按钮进编辑 | 字能选；右键「复制」；松手时处理编辑锁定 |
| 单线关 · 开发者模式 / 单线开 · 开发者模式 | 同上(对话区走同一条路) | 同上 |
| 观察窗(`?watch=1`,只读) | 点按钮展开/收起折叠 | 字能选(同一条 CSS);拖选后不切换折叠(上游已有保护);右键「复制」(原来就接 `copyMenu`,现在不再只限单线) |

### 消息类型

| 消息 | 原来能选吗 | 本 PR |
|---|---|---|
| 普通文字气泡(含代码、链接、`@file:` 引用) | 不能 | 能选；右键复制按气泡显示的样子(引用复制成路径/网址) |
| 只有图片的消息 | 无文字 | 不变：右键不出「复制」(`copyableMessageText` 为空) |
| 很长、被折成 4 行的气泡 | 不能 | 看得到的部分能拖选；右键「复制」复制整条(实测 165 字全在) |
| 后台进程通知 | 能(根节点本来就可选，不是按钮) | 查过，不改 |
| 助手之间的消息(`Message from 🤖 …`) | 能(同上) | 查过，不改 |
| 交接卡「X 交来的活」(只在多助手接力下出现) | 能(`<p>`,不是按钮) | 查过，不改 |
| 编辑框 | 能(contenteditable) | 不改 |
| 排队待发的消息(输入框上方) | 只是截断预览，还没发出 | 查过，不改；点铅笔会回到输入框，在那里能选 |
| Bot 群聊记录 | 能(`data-selectable-text`) | 查过，不改 |

### 操作

| 操作 | 单线关 / 开发者模式，改前 | 改后 |
|---|---|---|
| 拖选气泡里的字 | 选不中；松手那一下等于点击，直接打开编辑框 | 选中；不进编辑；放开编辑锁定 |
| 拖到气泡外面才松手 | 选不中；编辑锁定一直挂着 | 选中(可跨到回复);放开编辑锁定 |
| 选中后 ⌘C | 无内容 | 复制选中的部分(系统复制) |
| 选中后右键 | 无选区可复制 | 应用菜单「复制」→ 选中的部分(原有出口) |
| 没选字时右键(表情回应关，默认) | 什么都不出；编辑锁定挂着 | 应用菜单「复制」→ 整条，不加时间；不锁定 |
| 没选字时右键(表情回应开) | 表情选择器 | 不变 |
| 单击气泡 | 进编辑 | 不变(按下时锁定，松手再锁一次，幂等) |
| 有选区时点在选区上 | (原来不可能有) | 第一下只清掉选区，不进编辑；再点进编辑 |
| 有选区时点在选区外的字上 | (原来不可能有) | 进编辑，并补上编辑锁定 |
| 键盘：Tab 到气泡，Enter | 进编辑 | 不变；编辑框里 ⌘A ⌘C 可复制(原有) |
| 双击 / 三击选词选段 | 第一下就进编辑 | 不变：点击就是进编辑，这是上游交互 |

## 真 Chrome 实测(Playwright + 系统 Chrome)

开关关和开发者模式结果相同，下表一列写两种模式。「锁定」指对话区的 `data-editing`：按下气泡时为编辑框锁住滚动，编辑框关掉时放开。

| 操作 | 改前 | 改后 |
|---|---|---|
| 在第二条上拖选 | 选中 `""`，松手进编辑 | 选中「标题用第 1 个，发了以后」，不进编辑，不锁定 |
| 然后 ⌘C | 剪贴板不变 | 「标题用第 1 个，发了以后」 |
| 没选字时右键 | 不出菜单，锁定一直挂着 | 「复制」→ 整条「标题用第 1 个，发了以后把数据截图给你」，不锁定 |
| 拖到下面的回复上才松手 | 选中 `""`，不进编辑，锁定一直挂着 | 选区跨到回复，不进编辑，不锁定 |
| 有选区时点在选区上 | (选不出选区) | 不进编辑，选区清掉 |
| 有选区时点在选区外的字上 | (选不出选区) | 进编辑，锁定 |
| 单击气泡 | 进编辑，锁定 | 进编辑，锁定(不变) |
| 表情回应开，没选字时右键 | 表情选择器 | 表情选择器(不变) |
| 表情回应开，选了字再右键 | (选不出选区) | 「复制」→ 选中的部分 |
| 第一条很长，被折成 4 行，右键「复制」 | 不出菜单 | 整条 165 字 |
| 观察窗(`?watch=1`) | 选不中 | 拖选能选，不切换折叠；单击照样展开；右键「复制」 |
| 后台进程通知、助手之间的消息 | 能选 | 能选(不变) |
| 单线产品模式 | #522 的行为 | 同左(不变) |
