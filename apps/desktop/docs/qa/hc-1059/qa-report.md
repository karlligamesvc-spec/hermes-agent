## 实现

- `src/app/single-thread/single-thread-chat.css`（新）：每条规则都挂在 `[data-single-thread-chat]` 下面，借现有的 `data-slot` / `data-*` 选元素：
  - 你的消息：`button.composer-human-message`（只读气泡，编辑框是 div，不受影响）。用户消息不再吸顶，2 行折叠也去掉，整段显示。
  - APEX 的话：消息内容区的直接子元素 `.aui-md`，也就是每段文字。步骤、卡片、按钮都是它的兄弟节点，所以都在气泡外面。内容区改成纵向 flex、间距 10px，下一步按钮用 `order` 排到步骤后面。只有下一步块、没有字的文字段不画空气泡。
  - 尺寸用原型的 px（这里 1rem = 17px，`--dt-base-size`）。浅色用原型的色值，深色映射到主题变量。
  - 栏宽：在单线对话根上把 `--composer-width` 设成 720px，只影响对话区，输入框不受影响（见下面「和原型的出入」）。
- `components/assistant-ui/thread/index.tsx`：引入样式表；对话根在 `$singleThreadMode` 下加 `data-single-thread-chat`。没改 UserMessage、AssistantMessage、ThreadMessageListInner、ChatViewContent。
- `app/single-thread/turn-divider.tsx` + `segments.ts`：分隔线下面加一行居中时间。第一轮如果是今天或昨天，用「今天 14:20」「昨天 14:52」代替日期线，跟原型一样；新的一天、「新的一段」下面写「09:10」。时钟在 selector 里读，过了午夜来一条新消息，「今天」会跟着变成「昨天」。
- 文案：`i18n/single-thread-chat.ts` 加 `turnTime`（zh / zh-hant / en，ja / ar 退回英文），插在 `day` 后面。大文件 `en/zh/types.ts` 没动。

## 和原型仍有出入

- 输入框还是 64rem 宽，比 720px 的对话栏宽。输入框是 G4 的文件，这张票没动。
- 消息下面的复制 / 朗读 / 重答一行原样保留：平时看不见，鼠标停上去才出现，但仍占约 25px 高。所以一轮做完到下一轮之间比原型的 10px 宽。要不要藏，看决定 N10。
- 你发的图和文件排在你的气泡下面，靠右，不在气泡里面。放进气泡里要动 UserMessage 的结构，它已经到 CC 上限。
- 原型里你的消息里有链接卡片（「抖音 · 9.9 元收纳…」），这里还是原样显示网址。
- 紫色用原型的 `#6A4CEB`，不是主题的 `--dt-primary-solid`（APEX 主题算出来是 `#6556BF`）。换主题色时气泡不跟着变。
- 页面底色还是主题的白色；原型对话区是 `#F7F7F9`、卡片是白色。
- 时间行只出现在分隔线的位置：第一轮、新的一天、新的一段。原型里「08:00 · 你还没打开时 APEX 发的」和紫色「新消息」线是 G9。
- 步骤卡里每一步还是一行（标题、结果、「数据从哪来」），最后还有「用到的方法」一行；原型是两行，没有「用到的方法」（G12 / N10）。
- 「记下了」前面的 ✓ 和「APEX」前缀是 G12。
- 样片卡、成片文件卡、发布包草稿卡是 G6。

## 测试

- `src/app/single-thread/single-thread-chat.test.tsx`（新，19 条）：把样式表读进 jsdom，由 jsdom 的层叠算出每个元素实际拿到的样式。
  - 每条规则都挂在 `[data-single-thread-chat]` 下面；对话组件引入了样式表。
  - 只有产品模式的对话根带这个属性；开关关、开发者模式下，对话里没有任何元素涂了气泡色。
  - 涂紫色的正好是你的消息和第一个下一步按钮；涂灰色的正好是三段文字。
  - 用时 · 看过程、步骤、下一步、记下了、失败卡、活动行都不在任何气泡里；下一步排在最后。
  - 只有下一步块的文字段不画空气泡。
  - 你的消息不吸顶（用 `.sticky` 的替身规则证明覆盖生效）、靠右。
  - 时间行：今天 / 昨天 / 更早 / 新的一段四种，过午夜重新算；开关关和开发者模式下没有时间行。时钟用假时间固定，且必须早于真实时间：对话的「滚到底」循环会一直等到 `Date.now()` 追上它开始滚动的时刻，假时间比真实时间晚的话，测试结束后循环还在跑，测试环境拆掉时就报未处理的错误（第一次 CI 就挂在这里）。每条时间行用例结束前也先等滚动停下。
- `segments.test.ts`：`relativeDay`、`turnTimeLine` 的表驱动用例，含跨月的昨天。
- 本机：`src/app/single-thread`、`src/components/assistant-ui`、三个身份层测试和 `src/i18n` 共 90 个文件 867 条，`CI=true` 全绿；单线和身份层测试在 UTC、洛杉矶、上海三个时区各跑一遍都绿。`npm run check:lint` 0 error，`scripts/check --only health` 0 blocking。
